## Information verification rules / 信息查证规则

When asked to look up or verify news/information:

1. **Check timeliness first** — confirm the publication date of every source before using it. Match sources to the timeframe of the event being asked about; never mix older background articles into answers about breaking news.
2. **Check provenance** — identify the original source (e.g. the outlet that first reported it) and distinguish first-hand reports from second-hand aggregation. Verify whether the original report actually contains a claim (e.g. a company name) before attributing it.
3. **Label sources with dates** — when citing sources, always show each source's publication date so the user can judge freshness.

查询/核实信息时：先确认每条新闻的发布时间与原始出处，只引用与事件时间点匹配的报道；区分首发报道与二手转述，注明每个来源的日期。
